# Mouse Tweaks for Horizon

Mouse Tweaks enhances inventory item handling with 1:1 Minecraft Java parity for [Horizon](https://github.com/horizon-rust/horizon) (Minecraft: Java Edition 26.3 rewrite in Rust).

## Features

- **RMB Drag:** Hold the right mouse button and drag across empty or matching slots to deposit 1 item per slot evenly.
- **Shift + LMB Drag:** Hold Shift and drag the left mouse button across items of the same type to quickly transfer them between containers.
- **Scroll Wheel:** Scroll up or down over item slots to transfer items one by one.
- **Settings:** Fully toggleable in `Options > Mods > Mouse Tweaks`.
